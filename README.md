## Open in AndroidIDE / Android Studio
1. Copy `~/OctaCode` (this folder) into your projects directory.
2. Open as existing Gradle project, let AGP 8.5.2 + Kotlin 1.9.24 sync.
3. Run `app` on device (minSdk 26).
